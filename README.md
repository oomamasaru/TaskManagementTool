# Task Management Tool

PyQt6 で作成したローカル完結型のタスク管理ツールです。  
`docs` と `diagram` の要件/設計をもとに、以下を実装しています。

- カテゴリごとのタスク表示
- タスク追加・編集・削除・複製
- ドラッグ&ドロップによる並び替え/カテゴリ移動
- ステータス管理（完了時はメイン一覧から非表示）
- 完了済みタスク一覧での復活/完全削除
- ラベル管理・テキスト検索・ラベルフィルタ
- JSON 自動保存 + `.bak` バックアップ
- Undo / Redo（コマンド方式）

## 起動方法

```powershell
.\.venv\Scripts\python.exe src\main.py
```

初回起動時に `task_board.json` が自動作成されます。
